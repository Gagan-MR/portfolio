# Gagan M R — UI/UX & Product Designer Portfolio

**Version:** v1.8

A fast-loading, responsive, mobile-first portfolio showcasing multi-platform UI/UX design across **Web, Desktop, Tablet & Mobile**, interactive Figma prototyping, scalable design systems, brand identities, custom iconography, print/posters, and clean motion/video editing.

**Live Portfolio:** https://gagan-mr.github.io/portfolio/

---

## Key Features

- **100% WebP Asset Pipeline:** All brand marks, hero visuals, and project thumbnails use next-gen `.webp` files for fast mobile and desktop page loads.
- **Crisp Theme-Matched Mobile Side Drawer & Back-to-Top Button:** Slide-in mobile navigation drawer rendered above the backdrop blur overlay (`z-index: 200` over `z-index: 190`) and a floating scroll-to-top button styled for both Dark and Light themes.
- **Direct Phone & WhatsApp Contact Channels:** One-tap `tel:+919113870006` direct phone call row alongside WhatsApp (`+91 91138 70006`) and email triggers.
- **Uniform 24x24 Inline SVG Icon System:** Crisp, stroke-aligned inline SVGs with explicit width/height attributes so icons render identically across desktop and mobile.
- **6-Card Balanced Portfolio Grid:** Showcases 6 core case studies filterable across **UI/UX & Systems**, **Brand & Logos**, **Icons & Graphics**, and **Motion & Video**.

## Folder Structure

- `index.html` — Semantic long-scroll portfolio layout
- `README.md` — Repository documentation & setup guide
- `CHANGELOG.md` — Detailed Markdown release history (v1.8)
- `RELEASE_NOTES.txt` — Plain-text release notes (v1.8)
- `assets/icons/` — Brand mark & favicon (`logo.webp`)
- `assets/images/hero/` — Hero showcase visual (`hero-cover.webp`)
- `assets/images/projects/` — Case study thumbnails (`project-1.webp` to `project-6.webp`)
- `assets/videos/` — Optional local `.mp4` clips for Motion & Video modal
- `assets/docs/` — Resume PDF storage
- `css/tokens.css` — Dark & Light theme design tokens
- `css/base.css` — Reset, typography, SVG sizing & button primitives
- `css/layout.css` — Sticky navbar, desktop nav, mobile side drawer, grids & responsive breakpoints
- `css/components.css` — Cards, spotlight, timeline, contact panel, back-to-top & modal
- `js/projects-data.js` — Structured 6-project case study data array (`.webp` paths)
- `js/main.js` — Theme toggle, side drawer, back-to-top, dynamic renderer, filters & modal logic
