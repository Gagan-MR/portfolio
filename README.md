# Gagan M R — UI/UX & Product Designer Portfolio

**Version:** v1.5

A responsive, mobile-first portfolio showcasing multi-platform UI/UX design across **Web, Desktop, Tablet & Mobile**, interactive Figma prototyping, scalable design systems, brand identities, custom iconography, print/posters, and clean motion/video editing.

**Live Portfolio:** https://gagan-mr.github.io/portfolio/

---

## Key Features

- **Cross-Platform UI/UX Showcase:** Highlights responsive design systems and interactive Figma prototypes built across **Web, Desktop, Tablet & Mobile** viewports.
- **Uniform 24x24 Inline SVG Icon System:** Crisp, stroke-aligned inline SVGs with explicit width/height attributes so icons render identically across desktop and mobile without external CDNs.
- **Mobile-First Responsive Architecture:** Smooth horizontal filter pills on mobile, fluid `clamp()` typography, `44px+` accessible tap targets, and adaptive 3 -> 2 -> 1 column grids.
- **6-Card Balanced Portfolio Grid:** Showcases 6 core case studies filterable across **UI/UX & Systems**, **Brand & Logos**, **Icons & Graphics**, and **Motion & Video**.
- **Dark & Light Theme Switcher:** Instant theme toggling powered by CSS custom properties (`css/tokens.css`) with `localStorage` persistence.
- **Direct WhatsApp Lead Capture:** Sticky top **Hire Me** CTA and integrated contact rows wired directly to WhatsApp (`+91 91138 70006`).

- `css/components.css` — Cards, spotlight, timeline, contact panel & modal
- `js/projects-data.js` — Structured 6-project case study data array
- `js/main.js` — Theme toggle, dynamic renderer, filters & modal logic
