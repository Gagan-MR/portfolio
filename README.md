# Gagan M R — UI/UX & Product Designer Portfolio

**Version:** v1.3

A responsive, modular single-page portfolio showcasing end-to-end UI/UX product design, scalable Figma design systems, brand identities, custom iconography, print/posters, and clean motion/video editing.

**Live Portfolio:** https://gagan-mr.github.io/portfolio/

---

## Key Features

- **100% Self-Contained Inline SVG Icons:** Zero reliance on external icon CDNs—every UI icon, theme toggle icon, WhatsApp badge, and social mark renders instantaneously offline and online.
- **6-Card Balanced Portfolio Grid:** Displays 6 core case studies (2 rows x 3 columns) filterable across **UI/UX & Systems**, **Brand & Logos**, **Icons & Graphics**, and **Motion & Video**.
- **Dark & Light Theme Switcher:** Instant theme toggling powered by CSS custom properties (`css/tokens.css`) with `localStorage` persistence.
- **Direct WhatsApp Lead Capture:** Sticky top **Hire Me** CTA and integrated contact rows wired directly to WhatsApp (`+91 91138 70006`).
- **Interactive Case Study & Video Modal:** Structured **Challenge -> UX Architecture -> Deliverables -> Outcome** breakdown with optional inline `.mp4` video playback.

## Folder Structure

- `index.html` — Semantic long-scroll portfolio layout
- `README.md` — Repository documentation & setup guide
- `CHANGELOG.md` — Detailed Markdown release history (v1.3)
- `RELEASE_NOTES.txt` — Plain-text release notes (v1.3)
- `assets/icons/` — Brand mark & favicon (`logo.png`)
- `assets/images/hero/` — Hero showcase visual (`hero-cover.png`)
- `assets/images/projects/` — Case study thumbnails (`project-1.png` to `project-6.png`)
- `assets/videos/` — Optional local `.mp4` clips for Motion & Video modal
- `assets/docs/` — Resume PDF storage
- `css/tokens.css` — Dark & Light theme design tokens
- `css/base.css` — Reset, typography & button primitives
- `css/layout.css` — Sticky navbar, grids & responsive breakpoints
- `css/components.css` — Cards, spotlight, timeline, contact panel & modal
- `js/projects-data.js` — Structured 6-project case study data array
- `js/main.js` — Theme toggle, dynamic renderer, filters & modal logic
