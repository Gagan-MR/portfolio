OVERVIEW
--------
Release v1.4 upgrades the custom cursor suite based on UI/UX figure-ground
contrast principles: high-contrast neutral fills, crisp 1.1px borders, and a
signature theme-accent pivot dot across the geometric arrow, pointing hand, and
hollow I-beam text cursor.

DETAILED CHANGES
----------------
1. HIGH-CONTRAST GEOMETRIC CURSOR SUITE
   - Files Affected: index.html, css/components.css
   - Details: Replaced solid accent-filled cursors with high-contrast neutral
     fills (#f8fafc in Dark Mode, #0f172a in Light Mode) + crisp opposing
     borders and an accent-colored pivot dot so the cursor never blends into
     colored CTA buttons.

2. REPOSITORY DOCUMENTATION (v1.4)
   - Files Updated: README.md, CHANGELOG.md, RELEASE_NOTES.txt
   - Details: Synchronized all documentation files at version v1.4.
